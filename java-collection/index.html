什么是集合

集合和数组一样，可以保存一组元素，并且提供了操作元素的方法，使用方便

java 集合框架种的接口

java.util.Collection接口是集合框架的基础接口，定义了集合的基本操作，如添加、删除、查询等。
collection子接口有List、Set、Queue等，分别对应不同的集合类型。
