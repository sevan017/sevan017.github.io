1.确认_config.yml中url: https://welcomeme.cn配置正确
2.重新生成部署：hexo clean && hexo g -d

SSH免密未生效；检查服务器~/.ssh/authorized_keys与GitHub的SSH Key配置。

4.浏览器一直看到旧页面

1.服务器curl绕过浏览器缓存查看真实返回内容

2.返回旧源码：执行 sudo nginx -t && sudo systemctl reload nginx
3.返回新源码：浏览器缓存，打开无痕窗口，Ctrl+Shift+R强制刷新
